# Python-Work

A collection of beginner-friendly Python solutions to classic algorithmic challenges, including **FizzBuzz**, **Palindrome Number**, **Contains Duplicate**, **Two Sum**, **Best Time to Buy and Sell Stock**, and **Roman to Integer**.

---

## 🛠️ Requirements & Setup

- **Python Version:** Python 3.x
- No third-party dependencies required.

### How to Run

Clone the repository and execute the scripts directly using Python:

```bash
git clone [https://github.com/vinayak280710/Python-Work.git](https://github.com/vinayak280710/Python-Work.git)
cd Python-Work
python main.py
